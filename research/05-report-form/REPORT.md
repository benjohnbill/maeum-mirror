# 05 보고서 형식: "전문적으로 보이는" 문법

출처: 팀이 참고한 상용 기질·성격 검사 결과지(STC, 12쪽 A4, react-pdf 생성). 원본에는 이름과 생년월일이 있어 repo에 넣지 않았다. 아래는 구조만 적은 메모다.

## 원본의 장치

1. 표지 + DATA SUMMARY: 유형 코드 두 개(예: 기질 HLL, 성격 MLH)와 이름, 날짜.
2. 방법 공개: 검사가 무엇을 재는지, 두 축(타고난 기질, 형성된 성격), 점수 구간 규칙(L 0–30, M 31–70, H 71–100), 지표 3+3과 하위지표 표.
3. 양극 설명: 지표마다 Low 쪽 문장 ↔ High 쪽 문장.
4. 내 결과: 지표별 백분위 막대와 L/M/H 배지, 유형 이름 + 한 줄 슬로건.
5. 하위지표 표: 점 그래프, 각주 "인구 분포에 따라 계산된 백분위".
6. 해석: 서술 요약, 강점·약점, 영역별(연인, 친구, 커리어), 조언, "나를 위한 연습" 체크리스트.
7. 오른쪽 세로 목차 탭.

전문성은 장식보다 2번(방법 공개)과 5번(규준 각주)에서 나온다. 해석 문단(6번)은 누구에게나 맞는 문장이 많다(바넘 효과).

## 모바일 카드로 옮기기 (5분 세션, PDF 아님)

| 원본 | 마음 시간표 카드 |
|---|---|
| 표지 + 유형 코드 | 첫 카드: 이번 2주의 상태 이름 + 한 줄 + 핵심 숫자 2–3개 |
| 두 축 | 몸 지표(데이터로 측정) · 마음 지표(대화와 PHQ-9로 측정) |
| L/M/H 구간 | 평소 대비 구간(평소와 비슷 / 조금 다름 / 많이 다름). PHQ-9는 공식 절단점 |
| 백분위 점 그래프 + 규준 각주 | 지표 카드(접힘): 평소 범위 막대 위 최근 점, 각주 "본인 15–90일 전 대비" |
| 방법 공개 쪽 | "어떻게 쟀나" 카드(접힘): 지표, 비교 기준, 근거 강도 배지, 출처 |
| 강점·약점, 조언, 연습 | "이번 주 해볼 것" 카드: 2–3개, 데이터에 묶인 것만 |

규칙: 첫 카드는 바넘식으로 읽기 쉽게 써도 된다. 하지만 문장마다 실제 숫자 하나에 묶여야 한다. 근거 강도는 04 스트림의 `spec/metrics.json`을 따른다.
