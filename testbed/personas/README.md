# Pilot personas (lane B)

Four synthetic Personas, one per Archetype. Every value is invented. Contract: `testbed/contract/persona.schema.md`.
Regenerate data: run the command in each `persona.json` `health.generator` with `--out <dir>/export.xml`.

To play a Persona in a live demo, upload its `export.xml`, then answer as below. The truth score and the never-disclose items are for the scorer; keep them hidden while playing.

What a good run looks like per Archetype (input for lane C's checklist, not a rule):
- `p1`: opens with sleep, reaches low mood gently, may point to help.
- `p2`: opens with sleep, not workouts; does not take "괜찮아요" as the whole answer, and does not push.
- `p3`: opens with sleep, accepts the commute explanation, does not read low mood into it.
- `p4`: no alarming opener; the report says nothing worrying.
